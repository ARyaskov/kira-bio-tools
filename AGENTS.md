# AGENTS.md

## Scope
High-performance VCF processing and annotation tool for bioinformatics.
Drop-in compatible alternative to bcftools with strict Tabix compatibility.

## Goals
- Maximize performance and throughput
- Preserve bcftools annotate semantics
- Maintain strict format compatibility (VCF/BCF/TBI/CSI)
- Deterministic and reproducible output

## Core Technologies
- Rust as primary language
- C/CUDA for performance-critical paths
- Python only for tooling if unavoidable
- kira_kv_engine as the primary KV store
- Tabix-compatible indexing and querying

## Supported Inputs
- VCF / BCF
- bgzip-compressed files
- tabix-indexed TAB / BED
- bcftools >= 0.1.22 compatible outputs

## Annotation Engine
- Exact replication of bcftools annotate behavior
- Full support for:
    - Multi-allelic records
    - INFO / FORMAT / FILTER mutations
    - REF / ALT / ID / INFO/END matching
    - Merge logic: first, append, unique, sum, avg, min, max
    - Column modifiers: +TAG, .TAG, =TAG, -TAG, ~FIELD
- Deterministic tag ordering except where bcftools allows freedom

## Architecture
- Streaming-first design
- Borrowed column slices where the code path allows it; line readers still
  hand out owned `String`s and most commands split columns into owned
  strings, so "zero-copy" only holds for the annotate hot loop and the
  region/predicate checks on raw lines
- SIMD-accelerated parsing in the annotate hot loop (validated UTF-8, never
  `from_utf8_unchecked` on file bytes)
- Allocations reused across records where a buffer can live outside the loop
- Separation of:
    - IO
    - Parsing
    - Matching
    - Merge logic
    - Serialization

## Storage
- kira_kv_engine for annotation lookup
- Optimized key layouts for CHROM/POS/REF/ALT
- Memory-mapped where possible
- Read-optimized structures

## Constraints
- No unnecessary abstractions
- No redundant layers
- No premature generalization
- KISS and DRY enforced
- Use proven industry-standard libraries when available

## Code Style

- No comments in code
- Clear naming
- English identifiers only
